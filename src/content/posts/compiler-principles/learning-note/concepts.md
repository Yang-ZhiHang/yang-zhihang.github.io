## LL(1) & LR(1)

### LL(1)

LL(1) 即 Left + Leftmost，是一种自左向右解析的方式，(1) 表示解析的时候往下看 1 个符号。

具体的例子：

```
1 + 2 + 3
```

设定上下文无关文法：

```
expr -> term + expr
expr -> term
term -> number
```

则解析结构为：

```
expr(
    1 + expr(
        2 + expr(3)
    )
)
```

解析顺序为：

1. 1 + expr
2. 1 + (2 + expr)
3. 1 + (2 + 3)
4. 1 + 5
5. 6

本质是自顶向下的解析方式。

### LR(1)

LR(1) 即 Left + Rightmost。

解析结构为：

```
expr(
    expr(1 + 2) + 3
)
```

解析顺序为：

1. 1 + 2 = 3
2. 3 + 3
3. 6

本质是自底向上的解析方式。

## 单遍解释器

这里的单遍指的是从源代码到中间表示的过程中，对源代码的遍历次数。

笔者最近在实现的 Lox 单遍解释器即根据源代码流生成相应的字节码，因此叫单遍解释器。后续虚拟机读取字节码进行运行的逻辑不参与概念区分。

单遍解释器的优点在于：

1. 高效（生成中间表示的速度较快）
2. 内存占用小（不需要存储更高级的中间表示）
